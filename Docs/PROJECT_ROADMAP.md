## Governance
- New mechanics require a focused prototype only when they carry meaningful technical or design risk.
- Vertical slice scenes integrate only passed systems.
- Each promoted build must retain an explicit regression checklist.
- Art visuals and collision remain separate ownership layers.
- Any scope change requires explicit user approval before implementation.
